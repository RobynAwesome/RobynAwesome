# Repository Governance

This directory contains durable governance receipts for the repositories under `RobynAwesome`.

## Active ledgers

- [Fork Ledger](./FORK_LEDGER.md) — 36 forked repositories classified by state, provenance, purpose, mutation, consumer, validation gate, and archive/graduation condition.

## Current fork-state vocabulary

`RADAR` · `LEARNING` · `REFERENCE` · `CASE-STUDY` · `EXPERIMENT` · `PRODUCTIZED` · `ARCHIVED`

## Invariant

A repository name, fork relationship, or upstream claim is not sufficient proof of operational purpose. Purpose and state must be explicit and auditable.

`Fork -> Context -> Case -> Mutation -> Validation -> Graduation | Rejection | Archive`
